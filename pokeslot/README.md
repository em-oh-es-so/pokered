# Pokeslot scrolling reel test

Build with RGBDS 0.9.1 and Python Pillow: `make -C pokeslot`.

New entry point: src/scrolling.asm. Artwork is generated by scrolling_assets.py. Previous prototype sources remain as references, but are not compiled.

Start enters the machine from the title screen. A spins. Up/Down adjusts demo spin cost from 1 to 9. Select restores 200 demo coins while idle. Controls now read action buttons and directions in the correct groups. Bet display uses the corrected tile address.

Each of five reels follows the same six-symbol cyclic strip with its own offset and staggered stop. Cropped 24x24 symbols are encoded at zero- and four-pixel phases. The renderer moves the strip vertically through a fixed 72-pixel window, showing partial symbols between aligned stops. It waits for accessible video memory before tilemap writes. Frame pacing and visual smoothness still require a Delta test. This is not independent hardware scrolling per reel.

Artwork uses the selected cropped conversion, not manually retouched icons. Fonts are fitted into their tiles. Machine borders and separators are basic test artwork, not the original Game Corner frame.

There are no paylines, payouts, saving, audio, or selectable machines yet. Demo bets are per spin, not per line. Timing variation only changes demo stop positions; this is not a verified wagering RNG. All original assets remain intact. All 151 source sprites remain available. The first machine roster is Bulbasaur, Charmander, Squirtle, Pikachu, Eevee, and Ditto.

Test: title appears; Start enters; A rather than Right spins; symbols visibly travel vertically; reels stop left to right on whole-symbol boundaries; balance and bet are legible; holding A does not auto-spin; Up/Down respects 1-9; Select resets coins. Do not count this milestone as verified until the build and Delta checks pass.
